# Frontend — «Аким на 5 часов»

Здесь находится **только клиентская часть**: React + TypeScript + Vite, географическая 3D-карта Астаны на MapLibre, отдельный условный Unity WebGL-макет и Node-сервер для собранной статики. Правила бюджета, эффекты мер и Score рассчитывает [`../backend/`](../backend/README.md), а не браузер.

## Запуск

Нужен Node.js 20+ и npm. Из этой папки:

```bash
npm ci
npm run dev
```

Откройте <http://localhost:5173/>. Vite проксирует `/api/v1/*` на `http://127.0.0.1:8000`; другой адрес задаётся переменной `PYTHON_API_URL`. Python API запускается отдельно по [`../backend/README.md`](../backend/README.md). Если он недоступен, интерфейс переходит в явно помеченный деморежим; расчёт произвольного плана тогда недоступен.

Сборка и проверка production-режима:

```bash
npm run build
npm run serve
```

По умолчанию `serve` открывает <http://127.0.0.1:3000/>; порт меняет `PORT`. Этот сервер отдаёт Unity-файлы с `Content-Encoding: gzip` и правильными MIME-типами, а `/api/v1/*` проксирует на Python API. Открывать `index.html` через `file://` нельзя: WebGL и API требуют HTTP. Для другого хостинга нужно повторить настройку gzip-sidecar файлов из `public/unity/Build/`; простого SPA-fallback на `index.html` для них недостаточно.

## Как проверить основной сценарий

1. Запустите backend и frontend. В шапке должно быть `API · подключён`.
2. Нажмите «Загрузить пример»: интерфейс подставит контрольный план из задания.
3. Нажмите «Сохранить план», затем «Рассчитать». Результат, критические показатели и история должны прийти от Python API; контрольный Score для эталонного сценария — `56.54` при бюджете `95` по текущей документации backend.
4. Переключите район в списке или на карте: выделение синхронизируется в обе стороны. «3D квартал» показывает объёмные здания. «Локальная карта» переключает на включённые в репозиторий OSM-слои без внешнего тайл-сервиса. Режим «Unity» — отдельная интерактивная модель дорожной сети с условными данными.
5. В AI-блоке задайте вопрос: фронтенд отправит **только текст вопроса** в `/api/v1/scenarios/{id}/chat/messages`, затем загрузит сохранённую историю. Для ответа AI основной backend должен быть подключён к отдельному AI-сервису; при его недоступности интерфейс покажет ошибку, а не выдуманный ответ.
6. Для проверки ошибки остановите backend и обновите страницу: появится честно обозначенный деморежим и кнопка повторного подключения.

Клиент использует контракт [`../backend/docs/frontend-integration.md`](../backend/docs/frontend-integration.md): каталоги, валидацию, сохранение сценария с версией, расчёт, историю результатов и чат. ID сценария сохраняется в `localStorage`. Результат не вычисляется на фронтенде.

## Границы готовности

- Онлайн-режим «3D карта» использует реальные улицы, реку и здания из OpenStreetMap через [OpenFreeMap](https://openfreemap.org/). Для него нужен интернет. Если онлайн-подложка не загрузилась за 16 секунд, карта переключится на локальные OSM-слои; также это можно сделать кнопкой.
- Пять границ районов и облегчённые локальные слои находятся в [`public/data/astana/`](public/data/astana/README.md). Выгрузка сделана 23.09.2026 из OSM relations; снимок Overpass для границ датирован 22.09.2026. Прежний контур Nominatim для Есиля оказался устаревшим и заменён. Это **не официальные кадастровые данные**. В городе также есть район Сарайшык: пять районов задания не покрывают всю Астану.
- Локальные слои содержат 2 418 основных дорог, 29 речных сегментов, 110 парков и **демовыборку** 506 зданий около одной точки в каждом районе. Они не являются полным покрытием всех зданий и жилых улиц. Подробные источники, ограничения, размеры и лицензия — в [`manifest.json`](public/data/astana/manifest.json) и [описании выгрузки](public/data/astana/README.md).
- Подложка и геометрия лицензированы [ODbL OpenStreetMap](https://www.openstreetmap.org/copyright); атрибуция видна на карте. Все значения Score и эффектов мер относятся к симуляции, а не извлекаются из карты.
- Панель консультанта подключена к основному Python API и восстанавливает историю чата. Сам AI-сервис и его ключ настраиваются командой backend через `AI_SERVICE_URL`; фронтенд к AI-провайдеру напрямую не обращается. Streaming-ответа пока нет.
- Unity WebGL-сборка занимает около 35,5 МиБ на диске и около 10,2 МиБ при gzip-передаче. Для медленной сети доступна обычная схема районов.
- 3D-макет не является географически точной моделью Астаны и не участвует в расчётах.

## Структура

```text
frontend/
├── src/                    React UI, карта MapLibre, API-клиент и состояние сценария
├── public/data/astana/     Пять локальных GeoJSON-слоёв OSM, manifest и QA
├── public/unity/Build/     Unity WebGL-сборка и gzip-файлы
├── vite.config.ts          dev/preview: API proxy и Unity gzip
├── serve.mjs               production: статика, Unity gzip, API proxy
└── package.json            команды npm
```
