# Аким — фронтенд и городская песочница

React + TypeScript + Vite. Два режима: `/#astana` (исходный кейс) и
`/#sandbox` (вымышленный город «Новый Берег» с Three.js).
Файлы исходников находятся в `src/`, готовая сборка — в `dist/` после сборки.

## Запуск после клонирования

Node.js **22.16+** (проверено на 24), Python 3.12. В папке `frontend`:

```powershell
Copy-Item .env.example .env
npm ci
npm run dev
```

Linux/macOS: `cp .env.example .env`, затем те же npm-команды.
Откройте http://127.0.0.1:5173/#sandbox.

В `frontend/.env` находятся адреса сервисов, а не ключи:

```dotenv
PYTHON_API_URL=http://127.0.0.1:8000
AI_API_URL=http://127.0.0.1:8001
PORT=3000
HOST=127.0.0.1
```

Vite читает адреса из `.env` при запуске; переменные процесса имеют приоритет.
`PORT`/`HOST` относятся к `npm run serve`; для Vite используйте `--port`/`--host`.
При изменении адресов перезапустите сервер фронтенда.

### Python API

Следуйте [backend/README.md](../backend/README.md). Для песочницы достаточно
запустить backend: её расчёты не требуют БД. Вкладке Астаны нужна инициализированная
БД для сохранения сценариев. Для локального просмотра без PostgreSQL из `backend`:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
$env:DATABASE_URL = 'sqlite+aiosqlite:///./.venv/sandbox-local.db'
.\.venv\Scripts\python.exe -m city_simulator.init_local_db
.\.venv\Scripts\python.exe -m uvicorn city_simulator.main:app --host 127.0.0.1 --port 8000
```

Linux/macOS: используйте `.venv/bin/python` и `export DATABASE_URL=...`.
Локальный SQLite — отдельный режим предпросмотра; production PostgreSQL запускайте
с Alembic по инструкции backend. PostgreSQL-миграции с JSONB не предназначены для SQLite.

### ИИ

Следуйте [ai_service/README.md](../ai_service/README.md), заполните
`ai_service/.env` (OPENAI_API_KEY и OPENAI_MODEL), запустите из корня проекта:

```powershell
.\ai_service\.venv\Scripts\python.exe -m uvicorn ai_service.app:app --host 127.0.0.1 --port 8001
```

ИИ вызывается сервером. Нельзя помещать ключ в `VITE_*`, JavaScript или публичную папку.
Без настроенного ключа игра работает, а советник показывает ошибку сервиса.

## API и потоковые ответы

Одинаковые маршруты доступны через Vite dev/preview и Node production-сервер:

| Маршрут браузера | Получатель и назначение |
| --- | --- |
| `/api/v1/catalog`, `/indicators`, `/districts`, `/measures` | Каталоги Python API; последние три пути также с префиксом `/api/v1` |
| `/api/v1/scenarios/*` | Валидация, сохранение, расчёт, результат и история Астаны |
| `/api/v1/sandbox/v2/catalog` | Правила пяти районов и шесть улучшений |
| `/api/v1/sandbox/v2/simulate` | POST `{ "turns": [[{"district_id":"almaty","improvement_id":"repair"}]] }`; сервер восстанавливает игру |
| `/api/ai/chat`, `/api/ai/chat/stream` | JSON/SSE консультант Астаны |
| `/api/ai/sandbox/v2/chat`, `/api/ai/sandbox/v2/chat/stream` | JSON/SSE консультант пяти районов; получает выбранный район и весь план |
| `/api/ai/health` | Доступность процесса ИИ; не проверяет баланс/доступ к модели |
| `/api/v1/health`, `/api/v1/ready` | Доступность backend и БД |

Обе панели советника используют POST + fetch streaming. WebSocket не нужен.
`answer_delta` печатает текст; `complete` содержит проверенный отчёт: answer,
strengths, risks, recommendations, follow_up_question. Ошибка и оборванный поток
не превращаются в завершённый ответ. «Стоп» отменяет запрос, выход со вкладки — тоже.
Node-прокси не буферизует SSE, проверяет адрес получателя и закрывает upstream при отмене.
При внешнем reverse proxy отключите buffering и установите timeout не меньше 70 секунд.

История чата хранится в памяти панели (до 20 сообщений), передаётся с каждым
запросом и очищается при переключении режима/новой игре. Для постоянных аккаунтов
и истории потребуется отдельное серверное хранение. Контекст Астаны и песочницы разделён.

## Как играть

Одновременно показаны пять районов с названиями из кейса Астаны: Есиль, Алматы,
Сарыарка, Байконур, Нура. География вымышленная. У каждого района свои дороги,
воздух и образование; рейтинг района — среднее трёх показателей.
Начальный общий бюджет 200. Выберите до трёх проектов в любых районах и нажмите
«Следующий квартал»: стоимость списывается, улучшения применяются, доход +25
поступает после хода. Каждый проект строится один раз в каждом районе.
Цель — все 15 показателей не ниже 65 максимум за 12 ходов. Пустой ход позволяет накопить доход.
После победы или конца сезона начните новую игру.

Красные зоны — показатель ниже 40; янтарные — 40–64; зелёные — от 65.
Школа и парк появляются в выбранном районе, фильтры уменьшают дым. Плохие дороги
показывают выбоины, снижают скорость и увеличивают число машин. Ремонт убирает
повреждения; машины соблюдают дистанцию и стоп-линии, светофоры регулируют очереди.
Движение машин условное, не транспортная микросимуляция.
На метки можно нажимать; тот же выбор доступен карточками районов с клавиатуры.
Камера вращается перетаскиванием, масштаб меняется колесом. Есть пауза анимации.
Время суток плавно меняет небо, положение света, тени, окна, фонари и фары.
Полные сутки занимают три минуты; кнопки «День», «Ночь» и ползунок задают время вручную.

Браузер сохраняет только историю ходов в localStorage. При открытии backend заново
считает бюджет и значения. Это личная локальная песочница, не защищённый игровой аккаунт.
Если API недоступен, новые ходы недоступны; поддельных результатов и ответа GPT нет.
Вкладка Астаны сохраняет существующий явно отмеченный деморежим.

Проверочный ход: ремонт в Алматы, парк в Сарыарке и школа в Нуре.
После него бюджет 145, дороги Алматы 58, воздух Сарыарки 46, образование Нуры 68;
показатели других районов сохраняются. Сохранение v2 имеет отдельный ключ;
старые маршруты песочницы без `/v2` оставлены для совместимости.

## Сборка и размещение

```bash
npm test
npm run build
npm run serve
```

По умолчанию http://127.0.0.1:3000/#sandbox. Для командного сервера DevOps задаёт
адреса Python/AI сервисов и HOST в `.env`; ключ остаётся в ИИ-сервисе.
Не открывайте `dist/index.html` через file://: WebGL, модули и API требуют HTTP.
Production-сервер также корректно отдаёт gzip-сборку Unity для исходной вкладки Астаны.
Новая песочница использует Three.js и не зависит от Unity-сборки.

Тесты проверяют SSE с Unicode, обрывом и ошибками, раннюю доставку SSE через
реальный HTTP-прокси, отмену соединения, запрет смены upstream и восстановление игры.
Для сервера, доступного в интернете, DevOps должен добавить аутентификацию и лимиты
запросов к платному ИИ; текущий запуск по умолчанию доступен только на loopback.
