# Frontend — «Аким: живая карта решений»

React + TypeScript + Vite. Главный экран — карта Астаны с одной панелью решений. Расчёты, правила бюджета и AI принадлежат Python-команде: браузер не подменяет их собственной симуляцией.

## Запуск

Нужны Node.js 20+ и npm. Из `frontend/`:

```bash
npm ci
npm run dev
```

Откройте http://localhost:5173/. Vite проксирует `/api/v1/*` на `http://127.0.0.1:8000`. Другой адрес задаётся переменной `PYTHON_API_URL`; запуск Python описан в [backend/README.md](../backend/README.md). Если API недоступен, интерфейс показывает «Деморежим»: произвольные планы не рассчитываются, доступен только контрольный пример задания.

Production:

```bash
npm test
npm run build
PORT=3003 PYTHON_API_URL=http://127.0.0.1:8000 npm run serve
```

Откройте http://127.0.0.1:3003/. Без `PORT` используется 3000. `index.html` через `file://` не поддерживается. Node-сервер обслуживает статику и API-proxy, бизнес-логики в нём нет.

## Основной сценарий

1. **Город:** выберите район на карте или в верхнем списке. Камера приблизит район, справа появятся две главные проблемы, все десять показателей доступны по раскрытию. На телефоне панель открывается снизу.
2. **Добавить решение:** отфильтруйте каталог по направлению. Выбранная мера сразу создаёт проект на карте; удаление снимает его. В «Мой план» можно сменить район или перейти к объекту. Общегородская мера показана в каждом из пяти районов, но считается одним решением.
3. Нижняя полоса показывает количество решений и бюджет. До ответа валидации сумма помечена как оценка. Нажмите **Сохранить план**, затем **Рассчитать результат**.
4. **Результаты:** общий индекс, бюджет, критические показатели, изменения пяти районов, эффекты мер и история приходят из Python. Состояния «Сейчас / Мой план / После расчёта» переключаются без пересоздания карты; слой показателя окрашивает районы. До расчёта состояние «После» недоступно.
5. **Сценарии:** создание нового плана и возвращение к сохранённому вместе с результатом. При несохранённых изменениях смена сценария заблокирована. ID и несохранённый live-черновик хранятся локально в браузере.
6. **Обсудить план:** AI-советник открывается сбоку. Контекст и историю собирает сервер; фронтенд отправляет только вопрос. Распознанные названия районов и IDs мер в ответе доступны как кнопки перехода. До сохранения советник видит предыдущую сохранённую версию — об этом есть предупреждение.
7. **Показать жюри:** полноэкранный рассказ «Проблема → Решение → Результат». Кнопки «Далее/Назад» управляют камерой и слоями. Escape возвращает рабочий экран. Без расчёта итог не выдумывается.

Для быстрой проверки: «Попробовать пример» → сохранить → рассчитать. Контрольный результат текущего Python API: **52.56 → 56.54**, бюджет **95**, критических показателей **2 → 0**. Встроенный демопример использует значения исходного задания; источники явно разделены.

## Карта и 3D

- **Карта и проекты** — основной режим MapLibre. Онлайн-подложка использует [OpenFreeMap](https://openfreemap.org/) и OpenStreetMap. При недоступности сети через 16 секунд включаются локальные слои; можно переключить вручную.
- **Объёмный макет** — Unity WebGL с теми же пятью районами, реальной географией OSM и отдельным слоем моделей проектов M1–M14. Загружается только при выборе этого вида. Контракт — [UNITY-BRIDGE.md](docs/UNITY-BRIDGE.md).
- **Список районов** — резерв при отсутствии WebGL. План, каталог и API остаются доступны.
- Проекты — **условные визуальные обозначения**, не реальные адреса и не расчёт последствий. У слоя есть подписи «Проект». «Сейчас» скрывает проекты, «Мой план» возвращает. Геометрия базового города не переписывается.
- Локальные OSM-слои: 2 418 дорог, 29 речных сегментов, 110 парков и демонстрационная выборка 506 зданий. Высоты схематические. Это не полный цифровой двойник и не кадастровая карта.
- Районы `esil`, `almaty`, `saryarka`, `baikonur`, `nura` соответствуют заданию. Шестой район Сарайшык не включён: нельзя заявлять, что показана вся территория Астаны.
- Источники и лицензия: [описание выгрузки](public/data/astana/README.md), [manifest](public/data/astana/manifest.json), [атлас](public/unity/geo/atlas-report.json). Атрибуция **© OpenStreetMap contributors**, ODbL, видна в обоих видах. Noto Sans в Unity распространяется по [SIL OFL](public/unity/FONT-LICENSE.txt).

## API и хостинг

Основной контракт: [backend/docs/frontend-integration.md](../backend/docs/frontend-integration.md). AI-сервис подключает backend через `AI_SERVICE_URL`; ключи провайдеров **никогда не кладите в frontend, public или VITE_* переменные**. Streaming пока отсутствует. При отключённом AI выводится ошибка с ручным повтором, а не фиктивный ответ.

Unity хранится в gzip-sidecar файлах. Сервер должен отдавать URL без `.gz` с правильным `Content-Encoding: gzip`, MIME и `Content-Length`. Это уже сделано в `serve.mjs` и Vite middleware. Обычный SPA-fallback для отсутствующих Unity-файлов недопустим. WebGL + атлас передаются примерно за **10.8 МиБ** (11 306 684 байта gzip); полный размер raw WebGL — 37 781 994 байта. HTTP-заголовки в размер не включены.

## Проверки и структура

`npm test` проверяет все 14 типов проектов, общегородские меры, устойчивость размещения, удаление, смену района и неизменность исходных решений. `npm run build` проверяет TypeScript и production-сборку. Ручной QA — [WORKSPACE-QA.md](docs/WORKSPACE-QA.md).

```text
frontend/
├── src/App.tsx               Рабочий экран, результаты, показ жюри
├── src/ScenarioLibrary.tsx   Библиотека сценариев
├── src/AstanaMap.tsx         Географическая карта и проекты
├── src/UnityCityView.tsx     Загрузка WebGL и мост
├── src/projectPreview.ts    Только визуальные обозначения мер
├── src/useCitySimulator.ts  Состояние и операции Python API
├── src/ConsultantPanel.tsx  AI-диалог и контекстные переходы
├── public/data/astana/      GeoJSON, источники, лицензия, QA
├── public/unity/            Сборка, атлас, manifest и лицензия шрифта
├── scripts/                Проверки без браузера
├── docs/                   Контракты и QA
├── vite.config.ts          dev/preview gzip и API proxy
└── serve.mjs               production-статика и API proxy
```
