# Проверка «Живой карты решений» — 23.09.2026

Проверен production через `npm run build` / `serve.mjs`. Бэкенд и исходный Unity-проект не изменялись.

## Пройдено

- TypeScript + Vite production build.
- `npm test`: M1–M14, расширение общегородских мер на пять районов, устойчивые позиции при перестановке решений, удаление, смена района, неизменность исходных решений.
- Desktop 1280×720: добавление школы и парка, их объёмные обозначения на MapLibre. Удаление парка оставляет школу; «Сейчас» скрывает проекты, «Мой план» возвращает.
- 390×844: ширина документа 390 px, горизонтального скролла нет. Панель решений раскрывается снизу, бюджет и основное действие доступны.
- Unity `projects-v1` в основном интерфейсе: геоатлас отображается, парк появляется при добавлении, «Сейчас» скрывает его. Старый race запуска исправлен ожиданием кадров инициализации. Отдельный spike дополнительно проверил 14 → 1 → скрыто → 0 и оба направления выбора района.
- «Показать жюри»: три этапа, проекты на этапе решения, фактический результат на третьем шаге, Escape возвращает раздел и настройки рабочего вида.
- Python API из текущего backend запущен в отдельном временном окружении и SQLite БД, без AI-ключей и без изменения командных данных. Через браузер: сценарий → пять решений → сохранение → расчёт **52.56 → 56.54**, бюджет **95**, критические **2 → 0** → библиотека → новый сценарий → повторное открытие первого с решениями и результатом.
- AI-сервис намеренно отключён: вопрос получает понятную ошибку и кнопку ручного повтора. Успешный ответ модели здесь не проверялся — нужен сервис команды.
- Production: gzip атласа и WASM, корректные MIME, отсутствующий Unity-ресурс возвращает 404, а не HTML.

## Ограничения

- WebGL + атлас ≈10.8 МиБ gzip. Основной вид — карта; Unity загружается по выбору.
- Vite предупреждает о размере lazy-chunk MapLibre (>500 kB raw). Он отделён от основного JS; это не ошибка сборки.
- Здания и проекты схематические, проекты без точных адресов. Высоты не результат расчёта. Не заявлять полный цифровой двойник города.
- AI-переходы доступны по распознанным названиям районов / ID мер в сохранённом ответе. Реальная модель остаётся ML-команде.
- Холодная мобильная сеть, физический слабый телефон и успешный AI-ответ требуют отдельного интеграционного прогона.
